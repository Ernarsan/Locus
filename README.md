# Locus

Free and open-source iPhone location teleport. Tap the map, search a place, or drive a route — Locus injects coordinates through Apple’s **developer location service** into `locationd`, so Maps and other apps see the spoofed GPS (not just a Wi‑Fi lookup that outdoor GPS will overwrite).

## Features

- One-tap teleport (map pin or place search)
- Live joystick — walk / run / cycle / drive with light speed variation
- Walk/Drive routing on real roads & footpaths (MapKit)
- Draw a path or import / export GPX
- Background keep-alive + live status bar + drop alerts
- Favorites & recents
- First-run setup walkthrough
- Fully on-device — no analytics, nothing uploaded

File pickers often don’t work inside LiveContainer. Use one of these:

1. Long-press **Locus** → **Settings** → enable **Fix File Picker**, then try Import again.
2. Share the pairing file **into LiveContainer → Locus**.
3. Copy the RPPairing plist contents → in Locus use **Paste RPPairing from clipboard** (setup or Settings).

## How it works

Locus uses the MIT-licensed [idevice](https://github.com/jkcoxson/idevice) FFI to talk to Apple’s DVT location simulation over an on-device developer tunnel (the same class of mechanism Xcode uses).

**iOS 27:** Settings → **Pair on this iPhone** advertises `_remotepairing-pairable-host._tcp`. Confirm the 6-digit code under Settings › Privacy & Security › Developer Mode › Pair with Host — no computer.

**iOS 18–26:** import an **RPPairing** file once from [idevice_pair](https://github.com/jkcoxson/idevice_pair/releases).

Also install **[LocalDevVPN](https://apps.apple.com/us/app/localdevvpn/id6755608044)** (loopback tunnel, default `10.7.0.1`), then sideload Locus.

Start a teleport on Wi‑Fi first; the session can keep working on cellular afterward.

## Что было добавлено
1. **Управляемый таймер спуфинга**:
   - Быстрый выбор пресетов: `30 с`, `1 мин`, `5 мин`, `15 мин`, `30 мин`, `1 ч`.
   - Кастомный выбор времени (колесики: часы, минуты, секунды) в диапазоне от 5 секунд до 12 часов с запоминанием в `UserDefaults`.
   - Управление: «Старт», «Пауза / Продолжить», «Стоп», кнопки «+1 мин» и «-1 мин» (не снижает остаток ниже 5 секунд).
   - Предотвращение случайного смещения: если при активном таймере выбрать на карте другую точку, приложение запросит подтверждение — переместить симуляцию сейчас (таймер продолжит отсчёт) или отменить.
   - Полноценная машина состояний: отслеживание абсолютного времени окончания (`Date.now`), автоматический перерасчет при возвращении из фона.
2. **Фоновый режим и надежность**:
   - Зацикленный тихий аудиопоток `SilentAudioKeepAlive`, активный **только** во время работы таймера, предотвращающий засыпание приложения iOS при блокировке экрана.
   - Локальное системное уведомление при завершении таймера.
   - Автоматический сброс спуфинга (`LocationEngine.clear()`) при истечении таймера с повторами (до 3 раз с задержкой 1 сек).
   - Сохранение состояния: если приложение было принудительно закрыто системой или пользователем, при следующем открытии оно распознает истекший таймер и сбросит спуфинг.
3. **Выбор локации**:
   - Поиск мест и адресов через MapKit.
   - Экран ручного ввода координат с валидацией и кнопкой «Вставить из буфера обмена» (поддерживает форматы `55.7558, 37.6173`, ссылки Google/Apple Maps).
   - Быстрый доступ к «Избранному» с возможностью переименования и удаления.
   - Отображение координат и распознанного адреса (обратное геокодирование) прямо над кнопками таймера.

## Полная инструкция по настройке для iOS 18.7 (iPhone 15)

Для работы приложения **не требуется платный аккаунт разработчика Apple** и **не требуется наличие Mac**.

### Шаг 1. Включение режима разработчика на iPhone
1. На iPhone откройте **Настройки** → **Конфиденциальность и безопасность**.
2. Прокрутите вниз до пункта **Режим разработчика** (Developer Mode).
3. Включите переключатель и перезагрузите iPhone по запросу системы.
4. После перезагрузки подтвердите включение режима разработчика, введя код-пароль устройства.

### Шаг 2. Генерация файла RPPairing на компьютере
На iOS 18–26 прямое спаривание на устройстве недоступно — требуется один раз сгенерировать файл спаривания через утилиту `idevice_pair`:
1. Скачайте утилиту `idevice_pair` для вашей системы (Windows/Linux/macOS) со страницы релизов: [jkcoxson/idevice_pair](https://github.com/jkcoxson/idevice_pair/releases).
2. Подключите iPhone к компьютеру кабелем, разблокируйте экран и нажмите **«Доверять этому компьютеру»** (Trust).
3. В терминале/командной строке выполните команду генерации Remote Pairing:
   ```bash
   idevice_pair rppairing
   ```
4. Утилита создаст файл с именем `rp_pairing_file.plist` (или аналогичный `.plist`).
5. Передайте этот файл на iPhone (через Telegram/iCloud Drive/AirDrop или скопируйте его текстовое содержимое в буфер обмена).

### Шаг 3. Установка LocalDevVPN
1. Установите бесплатное приложение **[LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044)** из App Store.
2. Откройте LocalDevVPN и нажмите **Connect** (по умолчанию адрес туннеля `10.7.0.1`).
3. Разрешите добавление конфигурации VPN в диалоговом окне iOS.

### Шаг 4. Сборка IPA через GitHub Actions
1. Сделайте push или откройте вкладку **Actions** в вашем репозитории на GitHub.
2. Выберите рабочий процесс **Build Unsigned IPA & Run Tests** и нажмите **Run workflow**.
3. Дождитесь окончания сборки (~2–3 минуты).
4. Во вкладке завершённого запуска скачайте артефакт **Locus-Timer-ipa** (внутри архива находится файл `Locus-Timer.ipa`).

### Шаг 5. Подпись и установка (Sideloading)
1. Установите скачанный `Locus-Timer.ipa` на ваш iPhone 15 любым удобным способом с вашим личным сертификатом:
   - Через **SideStore** / **AltStore** прямо с телефона.
   - Через **Feather** / **Scarlet** / **Sideloadly** с компьютера.
2. Откройте установленное приложение Locus на iPhone.

### Шаг 6. Импорт файла спаривания в приложение
1. При первом запуске или в меню **Settings** нажмите **Import RPPairing**.
2. Выберите сохраненный файл `rp_pairing_file.plist` либо нажмите **Paste from clipboard**, если вы скопировали содержимое plist в буфер обмена.
3. Индикатор спаривания загорится зеленым цветом.

## Как пользоваться таймером
1. Убедитесь, что **LocalDevVPN** подключен.
2. Выберите желаемую точку на карте:
   - Тапом по карте (установится булавка).
   - Через строку поиска вверху.
   - Через кнопку ввода точных координат `mappin.and.ellipse` на карте.
   - Либо выбрав сохраненное место из Избранного (`star.fill`).
3. Нажмите кнопку таймера (иконка секундомера в нижней панели).
4. Выберите нужный интервал (например, `5 мин` или нажмите `Своё` для точной настройки).
5. Нажмите большую кнопку **«Старт таймера»**:
   - Симуляция запустится в выбранной точке.
   - Запустится обратный отсчет.
   - Активируется тихий фоновый режим.
6. Вы можете заблокировать телефон или свернуть приложение — таймер продолжит работу.
7. При необходимости используйте кнопки `+1 мин` или `-1 мин`, либо `Пауза`.
8. При наступлении `00:00`:
   - Приложение автоматически отправит команду сброса в Apple DVT.
   - Сработает виброотклик (Haptic Feedback) и появится баннер: *«Реальная локация восстановлена»*.
   - Если телефон был заблокирован, придет системное уведомление.

## Известное поведение (Known Behavior)
- **Удержание симуляции в iOS (`locationd`)**: Apple Developer Location Simulation работает на уровне системного демона `locationd`. Если симуляция включена, iOS будет сообщать поддельные координаты всем системным сервисам до тех пор, пока не будет вызван метод `location_simulation_clear` или устройство не будет перезагружено.
- **Принудительное закрытие (Force Kill)**: Если пользователь вручную «смахнет» приложение из меню многозадачности iOS во время работы таймера, операционная система завершит процесс приложения и остановит выполнение кода таймера. Однако, благодаря сохранению состояния в `UserDefaults`, **при следующем запуске Locus моментально обнаружит, что время таймера истекло, и незамедлительно отправит команду очистки симуляции**, восстановив реальный GPS!
- **Энергопотребление фонового аудио**: Во время работы таймера играет зацикленный беззвучный аудиотрек с категорией `.playback` и флагом `.mixWithOthers` (он не заглушает вашу музыку и подкасты). Это стандартный и надежный способ предотвратить усыпление процесса в iOS, но он расходует небольшой процент батареи (~1–3% в час). Как только таймер останавливается или завершается, аудиосессия мгновенно деактивируется.

## Устранение неполадок (Troubleshooting)
1. **Ошибка «Could not open the developer tunnel»**:
   - Проверьте, включен ли VPN в приложении LocalDevVPN.
   - Убедитесь, что iPhone подключен к сети Wi-Fi (первый старт сессии DVT требует активного сетевого интерфейса).
2. **Ошибка «Could not read the RPPairing file»**:
   - Файл спаривания поврежден или устарел. Сгенерируйте свежий файл через `idevice_pair rppairing` и импортируйте его заново.
3. **Баннер «Ошибка сброса локации»**:
   - Если при истечении таймера туннель кратковременно оборвался, приложение сделает 3 автоматические попытки с интервалом в 1 секунду.
   - Если связь не восстановилась, нажмите кнопку **«Сбросить сейчас»** на красном баннере в приложении, предварительно проверив статус LocalDevVPN.
4. **Приложения со встроенной проверкой симуляции**:
   - Как отмечено в базовом проекте, Locus симулирует локацию через стандартный сервис разработчика Apple. Отдельные приложения со специализированной античит-проверкой сканируют флаги симуляции и могут отклонять такие координаты. Это ограничение метода Apple DVT, а не ошибка Locus. Обычные приложения (Apple Карты, Яндекс Карты, 2ГИС, Telegram, Погода, Браузеры) работают с симулированной локацией на 100%.

## Чек-лист ручного тестирования (Manual Test Checklist)
- [ ] **1. Запуск 1-минутного таймера и блокировка экрана**:
  - Подключить LocalDevVPN.
  - Поставить точку на карте, выбрать `1 мин`, нажать «Старт таймера».
  - Заблокировать экран iPhone. Подождать 65 секунд.
  - Разблокировать устройство, открыть Apple Карты — убедиться, что геопозиция автоматически вернулась в реальное местоположение.
- [ ] **2. Пауза и продолжение**:
  - Запустить таймер на 5 минут. На отметке 4:30 нажать «Пауза».
  - Проверить, что отсчет остановился, а симуляция осталась активной в картах.
  - Нажать «Продолжить» — отсчет должен продолжиться с 4:30.
- [ ] **3. Корректировка времени (+1 / -1 мин)**:
  - При работающем таймере нажать `+1 мин` — время увеличивается на 60 сек.
  - Нажать `-1 мин` несколько раз — время уменьшается, но не падает ниже 5 секунд.
- [ ] **4. Досрочная остановка («Стоп»)**:
  - Во время активного таймера нажать «Стоп» — симуляция мгновенно выключается, реальная локация возвращается, таймер переходит в статус «Ожидание».
- [ ] **5. Смещение точки при активном таймере**:
  - Во время работы таймера нажать на другую точку на карте.
  - Должен появиться запрос: «Переместить симуляцию?».
  - При нажатии «Переместить сейчас» симуляция переходит в новую точку, таймер не сбрасывается.
- [ ] **6. Перезапуск после истечения (Relaunch after expiry)**:
  - Запустить таймер на 30 секунд. Смахнуть Locus из панели многозадачности (принудительно закрыть).
  - Подождать 40 секунд. Открыть Locus — приложение должно автоматически определить истечение времени, сбросить симуляцию и показать баннер «Реальная локация восстановлена».
- [ ] **7. Поведение при выключенном LocalDevVPN**:
  - Отключить LocalDevVPN. Попробовать запустить таймер.
  - Приложение должно показать понятное сообщение об ошибке без падения (crash).
